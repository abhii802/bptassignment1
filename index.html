Part A • Fundamental Attributes

Four Primary Characteristics of a Computer

Pillars of Digital Computing
10⁻⁹ to 10⁻¹² sec 01

1. High Speed

Executes billions of complex instructions per second. Internal operations are calculated in nanoseconds (ns) and picoseconds (ps), measured in MIPS and FLOPS.

Metric Standard: GHz Clock Frequency
G.I.G.O. Principle 02

2. Accuracy & Precision

Calculations are 100% mathematically deterministic. Unless supplied with erroneous input or faulty algorithms (Garbage In, Garbage Out), computations carry zero operational error.

Execution Guarantee: Deterministic Logic
Zero Fatigue Factor 03

3. Diligence

A computer is completely free from human tiredness, boredom, distraction, or monotony. It performs its billionth calculation with the exact same precision as the very first cycle.

Reliability Index: Continuous 24/7 Operations
Massive Memory 04

4. Versatility & Storage

Seamlessly shifts between scientific matrix computing, audio/video streaming, graphics rendering, and databases. Backed by vast non-volatile storage with instant data recall.

Capability: Polymorphic Multi-tasking
Part B • Evolutionary Timeline

Key Hardware Component in Each Generation

Vacuum Tube Thermionic Valve
1st Generation 1940 – 1956

Core Hardware: Vacuum Tubes (Thermionic Valves)

Used large, fragile evacuated glass tubes acting as binary electronic switches. Consumed massive electrical power, produced excessive heat, and suffered frequent filament burnout.

Memory: Magnetic Drums I/O: Punched Cards Code: Binary Machine Code
Pioneering Systems:

• ENIAC (18,000+ tubes)

• UNIVAC-I & EDVAC

• IBM 701

Transistors Solid-State Semiconductor
2nd Generation 1956 – 1963

Core Hardware: Discrete Transistors

Invented at Bell Labs. Solid-state semiconductor switches replaced fragile vacuum tubes. Reduced power consumption, slashed physical system sizes, and drastically increased reliability.

Memory: Magnetic Core Arrays Storage: Magnetic Tape & Disks Lang: Assembly, FORTRAN, COBOL
Pioneering Systems:

• IBM 1401 & IBM 7090

• CDC 1604

• UNIVAC 1108

Integrated Circuits SSI & MSI Chips
3rd Generation 1964 – 1971

Core Hardware: Integrated Circuits (ICs)

Pioneered by Jack Kilby and Robert Noyce. Hundreds of transistors integrated onto single silicon semiconductor dies. Introduced keyboard inputs, visual monitors, and time-sharing OS.

Integration: SSI & MSI Interaction: Keyboard & Monitors OS: Multiprogramming Timeshare
Pioneering Systems:

• IBM System/360 series

• PDP-8 Minicomputer

• Honeywell 6000

Microprocessor VLSI / ULSI CPU
4th Generation 1971 – Present

Core Hardware: Microprocessors (VLSI & ULSI)

Entire Central Processing Unit (CPU) condensed onto a solitary silicon microchip containing millions/billions of transistors. Led to Personal Computers (PCs), laptops, smartphones, and the Internet.

Integration: VLSI & ULSI Memory: Semiconductor RAM/ROM & SSD Ecosystem: GUI, Internet, Cloud
Pioneering Systems:

• Intel 4004 / 8086 / Core / Xeon

• IBM PC, Apple Macintosh

• ARM & Multi-Core SoCs

AI Chips & Qubits Neural & Quantum Architecture
5th Generation Present & Beyond

Core Hardware: Ultra-Large Scale AI Neural Processors & Quantum Qubits

Leverages massive parallel processing architectures, TPUs/NPUs for artificial intelligence neural networks, and superconductor quantum processors to solve intractable problems.

Technology: Neuromorphic & Superconductors Interface: Natural Language & Vision Frontier: Quantum Supremacy & GenAI
Pioneering Systems:

• Google TPU / Sycamore Quantum

• NVIDIA H100 / Blackwell

• IBM Condor / Quantum Heron

Flow of Data (Data Bus)

The Operational Cargo / Operands

Bidirectional

Carries the actual raw facts, variables, numeric values, character encodings, and program instruction machine words that are transformed by the computer.

• Propagation Channel: Input → RAM ↔ Registers/ALU ↔ RAM → Output/Storage
• Directionality: Bidirectional. Operands can travel to or from memory and CPU arithmetic units.
• Sizing / Width: 32-bit, 64-bit, or 128-bit parallel copper traces.
→

Flow of Control Signals (Control Bus)

The Orchestration Pulses / Conductor

Unidirectional / Broadcast

Consists of timing pulses, read/write strobes, and hardware directives generated exclusively by the Control Unit (CU) to synchronize every hardware block.

• Propagation Source: Control Unit (CU) → Memory, ALU, I/O Buffers, System Clock
• Directionality: Unidirectional. Originates from CU and broadcasts commands downward.
• Core Control Strobes: MEMR, MEMW, IOR, IOW, CLK, RESET, INTR, READY

Essential Control Signals Inventory

Micro-operations issued across the Control Bus to orchestrate hardware

Active-High & Active-Low Signals
MEMR (Memory Read)

Commands Primary RAM to place data stored at the addressed register onto the Data Bus.

MEMW (Memory Write)

Instructs Primary RAM to latch whatever bits are currently on the Data Bus into the target address.

IOR (I/O Read)

Alerts an addressed input port/controller to transfer buffered keyboard/sensor data onto the bus.

IOW (I/O Write)

Directs an output monitor/device buffer to receive and latch the contents present on the Data Bus.

CLK (Clock Signal)

Provides system-wide square wave synchronization pulses so all gate transistors trigger at lockstep.

INTR (Interrupt Request)

Asynchronous signal from peripherals demanding immediate CPU service via an Interrupt Handler.

READY / ACK

Handshake status flag informing the CPU that slow memory or I/O transfer is finished.

RESET

Terminates current execution, clears Accumulator, and sets Program Counter (PC) to start vectors.

Integrated Academic Summary

Core examination review curated by Dr. Abhishek Bhattacherjee

• Hardware Evolution Invariant:

While computer hardware has shrunken from room-scale Vacuum Tubes down to nanometer-scale Microprocessors and Quantum Qubits, the four bedrock characteristics—Speed, Accuracy (GIGO), Diligence, and Versatility—remain unchanging hallmarks of computation.

• The Signal Division of Labor:

Inside the computer block diagram, the Data Bus acts as the physical highway transporting numbers and words, while the Control Unit (CU) serves as the indispensable maestro, broadcasting timed pulses across the Control Bus without which no data can move.
